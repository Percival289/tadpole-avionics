# Welcome to Leapfrog Avionics!

Repository for Project Leapfrog's avionics software

## Technical Info

* **Language:** C++20
* **Compiler:**
* **Build System:** CMake
* **Generator:** Ninja?

## Some initial standards

* Compile with all flags and warnings enabled
* Use clang-format to clean up code before commit
* All pull requests (or commits?) will need to be statically analyzed with something like: 
	* clang-tidy
	* cppcheck
* We will vaguely adhere to MISRA C++ standards
* There will be strict memory management rules
